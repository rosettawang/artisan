Aug 6, 2026 — specs/ established, and the fork work brought forward

Not a spec run. The session that created this folder, recorded here so the next one does not rediscover any of it.

The app was replaced first. /Applications/Artisan.app went 3.4.0 → 4.2.0 (official arm64 DMG, notarized, Team ID 6M3Z6W45L4); the old bundle is in ~/.Trash/Artisan-3.4.0.app. master was fast-forwarded 433 commits to 784effc82 (4.2.1-dev). Settings migrated cleanly — the roaster and batch size survived.

An external MCP bridge was built and verified against the real roaster, at ~/Documents/artisan-mcp — outside this repo. It relays Artisan's Kaleido traffic over a WebSocket shim and injects guarded actuator commands. 102 checks pass across three suites, including a fake-Artisan client that reproduces the real handshake. It talked to the physical machine on this date. mcp-server exists because that bridge, being outside the app, cannot see the roast — only the wire.

Two hardware truths were established the hard way and are written up in kaleido-machine-adaptations: the CP210x adapter can wedge such that the OS itself cannot configure the port (stty fails identically to pyserial; only a physical replug clears it), and this machine answers {[TU]}, {[SN]} and {[PI]} with a bare {0} — no unit, no serial number, no event flags, ever.

Then the owner pointed at a second working copy in Google Drive (laurelate/AllArtisan/Artisan) — a 2025 fork on branch main, 11 commits of real work, 433 commits behind. This had been invisible from this clone because the work sat on origin/main while this checkout tracked origin/master. It was merged forward in 738dcd16c. Three conflicts, all from the same root cause: the fork had removed the in-app Designer in favour of a standalone window, and upstream had since kept and extended it. Both now coexist under distinct menu labels. The fork's self.ToolkitMenu.addAction() would have raised AttributeError at startup against current upstream, since ToolkitMenu is now assigned later than the action-creation block — fixed by moving the wiring into create_tools_menu().

The merge also invalidated the first draft of a spec. kaleido-machine-adaptations was written describing a clean slate; the merge showed a Kaleido adaptation already shipped in 2025 (BT-only mode). Finding 5 was added, and with it the discovery that its et_offset = -50.0 carries no unit while this Artisan runs in Fahrenheit.
